# سوق الشام الذهبي (Al-Sham Al-Dhahabi)

منصة ويب شاملة ومتعددة الخدمات تتضمن واجهات لطلبات تحويل الأموال، وعروض معارض السيارات الآلية، واتصالاً متكاملاً بقواعد بيانات PostgreSQL عبر Neon و Supabase.

## الميزات الرئيسية

* **نظام معارض السيارات**: تصفح وتفلترة وعرض مخزون المركبات مع المواصفات التفصيلية ومصفوفات الصور (`TEXT[]`).
* **طلبات تحويل الأموال**: واجهة آمنة ومنظمة لتقديم ومتابعة طلبات التحويل المالية.
* **إدارة الإعدادات الديناميكية**: لوحة إعدادات مركزية للتحكم ببيانات الاتصال، تشمل أرقام الهواتف، والواتساب، وتوزيعها ديناميكياً على كافة أزرار الاتصال في صفحات الموقع.
* **تكامل حديث لقاعدة البيانات**: متصل ببنية قوية لقاعدة بيانات PostgreSQL المستضافة على Neon.

## التقنيات المستخدمة

* **الواجهة الأمامية**: HTML5, CSS3, JavaScript (Vanilla), Tailwind CSS
* **الخلفية وواجهة برمجة التطبيقات**: Node.js, Express.js (يعمل محلياً على المنفذ 5000)
* **قاعدة البيانات**: PostgreSQL (Neon / Supabase)
* **أدوات الذكاء الاصطناعي**: مدمج مع مساعد VS Code و Google Gemini API
